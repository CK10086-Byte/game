# 坦克大战 · 反弹竞技场

## 设计

手机和电脑都能玩的俯视坦克竞技场。驾驶、绕墙、预测反弹、开火；每秒一发，十次反弹消失。保留五倍面积的九张地图、四季主题、四种补给、六位房间码与 2–4 人互联网联机。

本轮视觉方向是「微缩装甲竞技场」：橄榄绿、奶油白与高识别度橙色，实体金属坦克、清晰装甲轮廓、分层地面和障碍，手机 HUD 优先可读。局内持续三分钟或五次击毁，击毁后三秒复活。

## Game Forge 使用方式

参考仓库：https://github.com/npmiaman/game-forge
已读取 make-game、polish 与 game-feel 清单，按设计 → 核心反馈 → 完整对局 → 试玩 → 视觉检查流程升级既有游戏。原工具包独立放置于工作区 tools/game-forge，不打包进线上服务。

根据项目不增加依赖、Python 后端及现有联机要求，本轮保留原生 Canvas/Web Audio/Python；不迁移到 Phaser、Three.js、Vite，不安装桌面 Studio 或 Claude。原工具包 npm 指令不适用于这个 Python 项目，使用本项目的 Python/JavaScript 回归与真实浏览器试玩验证。

## 本轮重点

- 大厅和游戏界面重新设计，手机横竖屏及桌面安装入口保留。
- 开火事件驱动火光、后坐、炮声；命中、击毁、护盾和补给准确归属。
- 全屏可见的战斗播报、生命条、装填反馈、武器倒计时和击毁进度。
- 练习坦克以安全、可达的距离出生；联机出生及物理规则保持一致。
- 可见尺寸、静态地图缓存和特效数量有界，兼顾手机。
- 手机横屏镜头在地图边缘留出操作空间，角落复活的坦克避开摇杆和开火按钮；缩放、碰撞和桌面视野规则保持一致。

## 操作

电脑：W/S 前后移动，A/D 转向，空格开火，M 切换全图。手机：左摇杆驾驶，右按钮开火，支持双指；开局进入铺满战场。添加桌面后仍需联网。

## 电脑对手

房主在等待开局或本局结束后，可选择难度并点击「添加电脑」，也可在每个电脑下方修改难度或移除。真人与电脑合计最多 4 个席位，至少两名在线坦克手即可开局。电脑彼此也会交战，朋友可占用移除电脑后空出的席位；对战中不能调整电脑。

- 简单：发现新目标有反应延迟，瞄准存在偏差，重新寻路较慢。
- 标准：常规追击、绕墙和瞄准，保持原有训练强度。
- 困难：更频繁地规划路线，适度预判目标移动，并尝试躲避附近炮弹。

三档共享相同的生命值、移动速度、子弹伤害和一秒射击间隔，难度在复活与重赛后保留。单人练习默认添加一名标准电脑，可以自行增减；移除全部电脑后须先添加对手再开局。

电脑功能已通过新增引擎 12 项、HTTP 集成、手机界面与混合对局检查；三困难电脑可完成混战结算。本机单房间性能验收不代表公网多房间并发承载能力。

## 取舍

实时联机不加入全局暂停、命中停帧、慢动作、自动吸附补给、击退、闪避无敌或额外连击倍率，避免改变已有竞技规则和两端同步。视觉后坐只作用于绘制。无背景音乐，炮声/命中/奖励音通过 Web Audio 合成并支持静音记忆。采用统一程序绘制风格，不加载大体积 3D 资源。

## 验收状态

已通过原引擎 9 项、事件/练习出生 8 项、HTTP 集成 6 项及 JavaScript 控制器、手机多指、相机缓存回归。真实浏览器已检查桌面、390×844 竖屏、844×390 横屏的大厅、开局、射击、返回房间和刷新恢复，无控制台错误。测试发现并修复了拾取事件字段冲突、旧手机 findLast 兼容与跨局提示残留。真实手机性能和主屏幕安装仍需实机复验。

手机横屏新增 24 组尺寸与角落位置检查，确保坦克主体避开双侧底角操作区，小地图视野框保持在地图范围内。公网双客户端已验证房主开局、移动、发射、房主移交与离房。

## 视觉检查

按 Game Forge 的可读性标准进行本地截图比较，修复直接影响成品的项目：大厅缺少游戏主视觉；战场地面缺少层次；射击缺少炮口与后坐反馈；手机全屏遮住播报；生命/装填只有小字。手机首屏检查另修复了装饰英文与规则统计重叠。用户已授权整体重做，本轮直接保留完成的改进，不要求用户逐项批准视觉修复。
